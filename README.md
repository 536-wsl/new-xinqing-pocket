## 🚀 快速启动（推荐）

### 方式一：一键启动（Windows）
双击运行 `start.bat`，后端服务会自动启动在 `http://localhost:3001`

然后在浏览器中打开 `index.html` 即可使用。

### 方式二：手动启动
```bash
# 1. 安装依赖（首次运行）
npm install

# 2. 启动后端服务
npm run server
# 或
node server.js

# 3. 在浏览器中打开 index.html
```

## ❓ 常见问题

### Q1: 为什么 AI 回复很慢？
A: 第一次请求可能需要初始化连接，后续会更快。如果持续很慢，请检查网络连接。

### Q2: 提示"连接失败"怎么办？
A: 
1. 确认后端服务已启动（运行 `start.bat` 或 `npm run server`）
2. 检查控制台是否有错误信息
3. 尝试访问 `http://localhost:3001/api/chat` 确认后端正常

### Q3: 如何更换 API Key？
A: 编辑 `.env` 文件，修改 `DASHSCOPE_API_KEY` 的值，然后重启后端服务。

### Q4: 可以在手机上使用吗？
A: 可以！将手机和电脑连接到同一 WiFi，然后：
1. 查看电脑的局域网 IP（如 192.168.1.100）
2. 修改 `.env` 中的配置或在前端 CONFIG 中改为 `http://192.168.1.100:3001/api/chat`
3. 在手机浏览器中访问 `http://192.168.1.100:3001/index.html`
